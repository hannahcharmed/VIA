# VIA

**Travel by way of trust.** Stays chosen by creators you already follow.

A three-sided creator-economy travel marketplace: creators apply for content trades, stay owners host them and get tracked deliverables, travelers book stays curated by creators they follow.

## Quick start

```bash
# Open the prototype in your browser (no build step)
open app/index.html

# Regenerate the deck
cd deck && npm install && node build-deck.js

# Regenerate the business plan + playbook
cd plan && npm install && node build-plan.js && node build-playbook.js
```

## Folder structure

- `app/index.html` — interactive prototype (24 screens across 3 personas)
- `deck/` — pitch deck source (`pptxgenjs`)
- `plan/` — business plan + execution playbook source (`docx`)
- `outputs/` — latest rendered files
